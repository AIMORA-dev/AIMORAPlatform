# AIMORASymbols

`AIMORASymbols` is the public content owner for AIMORA's original semantic primitive-vector symbol grammar. It owns symbol geometry, semantic ports, snapping and label anchors, diagram profiles, operating-state and level-of-detail variants, mappings, licences, accessibility metadata, and provenance.

The canonical symbol representation is deterministic open text using bounded geometric primitives such as lines, polylines, arcs, circles, ellipses, and polygons. SVG is not the canonical symbol, runtime scene, drawing, or publication intermediate. An SVG adapter may be admitted later only as derived exchange output and cannot become an engineering owner.

The same canonical symbol definition is intended to compile into:

- the native AIMORAStudio retained scene;
- deterministic vector PDF drawing commands;
- DXF block definitions and inserts;
- renderer-independent geometry and semantic-port tests.

The initial AIMORA profile remains intentionally empty until its primitive grammar is implemented and qualified. No IEC-, ANSI/IEEE-, ETAP-, DIgSILENT-, AutoCAD-, manufacturer-, standards-body-, logo-, font-, or organization-derived artwork is claimed without an original implementation or exact documented redistribution right.

A symbol is a projection of a Julia-owned asset, not a physical model. Moving, rotating, restyling, relabelling, or removing a projection from one view must not silently change topology or delete the physical asset.
