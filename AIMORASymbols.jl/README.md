# AIMORASymbols

`AIMORASymbols` is the minimal public owner reserved for SVG symbol artwork, semantic ports, diagram profiles, mappings, licences, and provenance. The initial AIMORA profile is intentionally empty: no IEC-, ANSI-, manufacturer-, or standards-derived artwork is claimed without a documented source and redistribution right.
