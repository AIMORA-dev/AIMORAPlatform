# AIMORAProject.jl

`AIMORAProject.jl` is the public owner for AIMORA's canonical semantic project model, typed revisions, transactions, commands, queries, provenance, and view metadata. It contains no solver, GUI toolkit, parser duplication, executable callback, or private runtime type; existing engine consumers remain canonical until an authorized migration moves them to this public boundary.

The current semantic layer provides immutable project/global IDs, namespaces, typed references, exact unit-aware quantities, provenance, uncertainty, checksummed artifacts, callback-free schemas, separated physical/signal/event/scenario/workflow/view graphs, common physical assets with exact study realizations, reusable nested definitions and independent instances, and declarative continuous/discrete/sampled/event-driven/hybrid control networks. Event calendars declare exact relative, absolute, sampled, or bounded condition triggers plus priority, target, reset, and rollback contracts. Scenario inheritance applies deterministic stable-ID patches through the same validated commands used by Julia and future GUI clients, producing immutable materializations with content hashes, changed owners, and dependency invalidations. No event, control, or scenario numerical behavior executes in this package.

Run `julia --project=. examples/canonical_primitives.jl` for primitive construction, `julia --project=. examples/transactional_project.jl` for revisions and transactions, `julia --project=. examples/semantic_graphs.jl` for typed topology, `julia --project=. examples/canonical_assets.jl` for shared physical assets and study realizations, `julia --project=. examples/reusable_subsystem.jl` for deterministic hierarchy expansion, `julia --project=. examples/control_network.jl` for an inert sampled controller with explicit held state, or `julia --project=. examples/event_scenario.jl` for exact event declarations and immutable scenario resolution.
