# AIMORAProject.jl

`AIMORAProject.jl` is the public owner for AIMORA's canonical semantic project model, typed revisions, transactions, commands, queries, provenance, and view metadata. It contains no solver, GUI toolkit, parser duplication, executable callback, or private runtime type; existing engine consumers remain canonical until an authorized migration moves them to this public boundary.

The current semantic layer provides immutable project/global IDs, namespaces, typed references, exact unit-aware quantities, provenance, uncertainty, checksummed artifacts, callback-free schemas, separated physical/signal/workflow/view graphs, common physical assets with exact study realizations, reusable nested definitions and independent instances, and declarative continuous/discrete/sampled/event-driven/hybrid control networks. Control declarations use typed external and block ports, complete initialized state inventories, exact scheduler and computational-delay contracts, explicit measurement/actuator boundaries, TACS import provenance, and declared algebraic-loop solvers without executing controller numerics. Immutable projects and revisions add typed commands, validated transactions, rollback, deterministic replay and undo, exact invalidation signals, an explicit unverified developer path, and revision-pinned queries.

Run `julia --project=. examples/canonical_primitives.jl` for primitive construction, `julia --project=. examples/transactional_project.jl` for revisions and transactions, `julia --project=. examples/semantic_graphs.jl` for typed topology, `julia --project=. examples/canonical_assets.jl` for shared physical assets and study realizations, `julia --project=. examples/reusable_subsystem.jl` for deterministic hierarchy expansion, or `julia --project=. examples/control_network.jl` for an inert sampled controller with explicit held state.
