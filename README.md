# AIMORAFormats.jl

`AIMORAFormats.jl` is the public Julia owner for restricted YAML, canonical JSON, TOML, CSV/JSONL, migrations, source maps, diagnostics, and admitted import adapters. It contains no solver construction.

The current public surface admits bounded UTF-8 source documents, exact byte/line/column spans, deterministic diagnostics, solver-independent located format values, typed operation results, and an inert restricted-YAML parser and deterministic emitter. `parse_restricted_yaml` accepts block and flow mappings and sequences, quoted and plain strings, exact finite JSON-style numbers, lowercase booleans and null, and comments. It rejects duplicate keys, implicit legacy booleans, implicit dates, ambiguous or nonfinite numbers, tags, anchors, aliases, merge keys, directives, document markers, block scalars, tab indentation, invalid Unicode escapes, and configured resource-limit violations with source-located diagnostics.

`serialize_restricted_yaml` writes deterministic single-line flow YAML while preserving mapping insertion order and sequence order. Reserved project envelopes such as `$ref`, `$artifact`, `extends`, patches, registered-function fields, and `$expr` remain ordinary inert mappings and strings: this package does not resolve references, open artifacts, evaluate expressions, execute Julia, load plugins, or access external resources. Bulk formats, structural schemas, migrations, project-directory resolution, and import adapters remain unavailable until their executable packets pass; repository presence does not imply support for them.

`parse_json` admits exact source-located JSON with arbitrary-precision integers and decimals while rejecting comments, duplicate keys, nonfinite or ambiguous numbers, invalid escapes, invalid Unicode, trailing data, and resource-limit violations. `serialize_canonical_json` emits UTF-8 with mapping keys ordered by Unicode scalar value, sequence order unchanged, shortest controlled string escapes, normalized exact integers, and normalized decimals as `coefficient` followed by lowercase `e` and the base-ten exponent. Decimal zero is `0e0`, negative zero is `-0e0`, and neither is collapsed into integer zero. `canonical_json_sha256` returns the lowercase SHA-256 of those exact bytes; presentation order, YAML comments, whitespace, and source spans therefore do not own content identity. This is AIMORA's exact canonicalization profile rather than an IEEE-754 JSON Canonicalization Scheme implementation.

`parse_format_lock` and `serialize_format_lock` own deterministic `aimora-lock-v1` TOML for schema, catalog, plugin, import, and automation dependency families. Every entry pins an exact version, revision hash, SHA-256, licence, bounded compatibility range, portable source, trust class, provenance, permissions, entrypoint/environment where executable code is declared, and bounded resource policy. Unknown fields, versions, families, floating compatibility, malformed or conflicting identities, credentials, absolute/local paths, and family/trust mismatches fail with source-located diagnostics. `inspect_julia_environment` hashes and inspects inert `Project.toml` and `Manifest.toml` text and their direct dependency pins; it never instantiates an environment, downloads a package, grants a permission, or loads or executes Julia code.
